# 취약점 진단 실습실

Linux 계정관리 01~08의 학습 → 코드 작성 → 통합 SH 저장 → CentOS 실행 안내 → TXT 결과 리뷰를 연결하는 정적 교육 사이트입니다.

## 구성

- 8개 학습 파트, 기준·코드 범위·출처 위치·답 선택 뒤 해설
- 학생 정보와 Linux 계정을 반영한 UTF-8/LF 통합 SH 한 파일
- TXT의 원문 상태·행 번호·근거·상세 결과·집계·다음 확인
- 흑백 밝은/어두운 화면, 모바일 목차, 브라우저 내부 PDF 직접 저장

TXT와 편집 코드는 브라우저 안에서 처리합니다. 서버 업로드·외부 AI·로그인·영구 저장 기능이 없습니다. SH 입력과 학생 코드 전체 자동 채점은 지원하지 않으며, 근거 없는 원인은 확정하지 않습니다. 새로고침 전에 작성한 코드를 저장해주세요.

## 공개 범위

이 저장소에는 공개용 사이트 코드와 독립적으로 만든 가상 예시·자동 테스트만 있습니다. 교수 PDF·PPT·사진·녹음·전사 원문, 실제 과제 SH/TXT, 개인 정보가 들어 있는 검증 기록과 로컬 경로는 포함하지 않습니다. 자료명·물리 페이지·전사 위치와 재작성한 학습 설명만 안내합니다. 모든 samples 파일은 가상 자료이며 실제 서버 점검·제출 결과가 아닙니다.

## 로컬 실행과 검증

Node.js 18 이상에서 다음을 실행합니다. 별도 패키지 설치가 필요하지 않습니다.

~~~sh
node server.cjs
npm test
~~~

로컬 주소는 http://127.0.0.1:4174/vuln-diagnosis-lab/ 입니다. GitHub Pages의 저장소 하위 경로를 같은 형태로 확인할 수 있습니다. 서버는 docs 폴더의 허용한 정적 파일만 제공합니다. 자동 테스트는 가상 입력만 사용하며 진단 코드를 실제 시스템에 실행하지 않습니다.

## GitHub Pages

Settings → Pages에서 Source를 Deploy from a branch, Branch를 main, 폴더를 /docs로 지정합니다. 배포 후 기본 주소는 https://rbtjd215.github.io/vuln-diagnosis-lab/ 입니다. 사이트 파일은 docs 아래에 있으며 .nojekyll을 포함합니다.

## 해석 범위

GOOD는 해당 코드 조건의 충족 기록이며 전체 안전을 뜻하지 않습니다. BAD는 학생 코드 오류를 뜻하지 않습니다. 교안 기준과 예제 코드의 좁은 검사 범위, 05 최소 기간 기준 차이, 07 단일 명시 구성원 실습 조건, 08 실습·교안 기준을 구분합니다. 원음·교수 의도가 확인되지 않은 설명은 미확인 표시를 유지합니다. 운영 환경의 최신 보안 지침으로 일반화하지 않습니다.

새 생성물의 실제 CentOS 실행과 학생 사용성·교육 효과는 별도 확인 대상입니다. PDF 직접 저장은 한글 페이지 이미지 형식으로 텍스트 검색·선택을 지원하지 않습니다.
