≡ 교안의 보안기준

기본 계정이 기본 패스워드를 사용하는 경우 추측공격에 악용될 수 있다는 것이 교안의 위험 설명입니다. 계정이 있다는 사실과 기본 패스워드를 실제로 사용한다는 사실은 따로 확인해야 합니다.

  • 미사용이 확실한 계정과 의심스러운 계정 확인
  • lp·uucp·nuucp 및 guest·test 같은 계정 검토
  • 퇴직·전배·휴직·계약해지자 계정 관리
  • 로그인이 불필요한 시스템 계정의 Shell 제한
교안 p41 · 자료 위치 안내

이번 코드는 어디까지 검사할까요?

/etc/passwd에서 lp:|uucp:|nuucp: 패턴이 있는 행의 수를 셉니다. 미사용 여부·인사 변동·실제 비밀번호를 모두 확인하는 코드는 아닙니다. GOOD도 이 검색 범위 안에서 읽습니다.

이 패턴은 행 문자열 검색이라 xlp:도 일치할 수 있습니다. 계정명 필드의 정확 일치 검사와 구분합니다.

● ● ●조회 → 집계 → 비교BASH
01   계정 파일에서 패턴 찾기
cat /etc/passwd |
  grep -E "lp:|uucp:|nuucp:" |
  wc -l

0 검색된 행이 없음

1 이상 검색된 행이 있음

숫자는 줄 번호가 아니라 검색 후 남은 행의 개수입니다.

02 / WRITE

코드를 읽고, 수정하고, 저장하기

선택한 파트의 본문을 작성하고 실제 01~08 코드가 담긴 SH 한 파일을 저장합니다. 이동해도 편집한 내용은 유지되며 새로고침하면 초기화됩니다.

예시 정보입니다. 본인 정보로 바꿔주세요.
학번·이름은 파일명, Linux 계정은 07의 본인만 조건에 사용합니다. 서버로 보내지 않습니다.

통합 파일은 다른 SH를 호출하지 않습니다. 07은 명시 구성원이 본인 하나인지 확인하는 수업용 조건입니다.

01은 RESULT 변수를 설정하고 공통부가 출력합니다. 02~08은 머리글·주 RESULT를 포함한 파트 블록입니다. 각 파트에서 주 RESULT가 한 번 기록되도록 작성해주세요. 공통 준비·SUMMARY는 전체 미리보기에서 확인합니다. 작성한 코드는 자동 채점하거나 실행하지 않습니다. 새로고침하면 작성 내용은 초기화됩니다.

03 / RUN ON CENTOS
CentOS에서 실행하고 TXT 가져오기
사이트는 CentOS에 연결하거나 명령을 실행하지 않습니다. 본인의 실습 VM에서 진행해주세요.

        
1
새 실습 폴더로 SH 옮기기
공유 폴더나 파일 전송 도구로 저장한 SH를 옮깁니다. 실제 과제 최종본과 분리된 새 폴더에서 진행해주세요. 같은 이름의 결과 TXT는 실행할 때 새로 기록됩니다.
mkdir -p ~/account-learning
cd ~/account-learning
이 폴더 안에 다운로드한 SH를 넣은 뒤 다음 순서로 진행합니다.
2
Bash 문법 확인
bash -n은 실행하지 않고 문법을 확인합니다. 아무 출력이 없고 종료 상태가 0인지 확인하세요. 오류가 나오면 코드와 표시된 줄을 먼저 다시 봅니다.
3
실행하고 결과 확인
bash 파일명으로 읽어 실행하므로 실행 권한을 777로 줄 필요가 없습니다. 예제는 계정 정보를 조회하고 현재 폴더에 TXT를 만듭니다.
4
TXT를 이 컴퓨터로 가져오기
생성된 를 Windows로 옮깁니다. UTF-8 TXT를 선택하고 01~08 주 결과·근거·상세 상태·SUMMARY·[END]를 확인하세요.
TXT 결과 리뷰로 →

        
실행이 막혔을 때
Linux 폴더와 파일 이름이 맞는지 확인하고, SH가 UTF-8·LF인지 봅니다. 기본 다운로드는 이 형식을 사용합니다. 조회 실패는 CHECK로 기록할 수 있으므로 원문 오류를 함께 읽습니다. BAD만으로 문법 오류나 불필요한 계정이라고 판단하지 않습니다.

교안 p41은 미사용이 확실한 계정과 의심스러운 계정을 검토·삭제하고, 로그인 불필요 계정의 Shell을 제한하도록 안내합니다.
  1. 계정 행과 검색 행 수, 기록된 오류를 확인합니다.
  2. 관리 목적과 실제 사용 중인 서비스, 계정이 필요한 이유를 실습 환경에서 확인합니다.
  3. 미사용이 확실한 경우에만 관리자의 검토 아래 교안의 조치 예시를 학습합니다.
  4. 필요한 보완 뒤 같은 스크립트를 다시 실행하고 새 TXT의 근거와 결과를 비교합니다.
cat /etc/passwd |
  grep -E "lp:|uucp:|nuucp:"
echo $?
마지막 숫자는 직전 검색의 종료 상태입니다. 0은 일치 행 있음, 1은 일치 행 없음이며 행 수와 다른 값입니다. 오류는 출력 원문도 함께 확인합니다.

01 교안의 조치 예시와 미확인 문구
p41의 userdel lp, userdel uucp, userdel nuucp는 삭제 조치의 예시입니다. BAD 또는 이름만 보고 자동으로 적용하지 않습니다. 계정 의존 서비스를 검토하고 미사용이 확실한지 먼저 확인합니다. 사이트는 이 명령을 실행하거나 생성 코드에 넣지 않습니다.
같은 페이지는 /bin/false로 Shell을 수정하는 경우 보안상 문제가 발생할 수 있으므로 삭제를 권고한다고 적습니다. 그 구체적인 이유와 앞의 Shell 제한 기준과의 적용 구분은 자료만으로 확인하지 못했습니다. 교안 문구와 실제 환경 검토를 구분합니다.
