02 / WRITE

코드를 읽고, 수정하고, 저장하기

입력 정보 → 코드 작성 → 작성 도움말 → 전체 미리보기·저장 순서로 진행합니다. 선택한 파트의 내용을 수정하고 01~08 코드가 담긴 SH 한 파일을 저장합니다. 새로고침하면 편집 내용은 초기화됩니다.

통합 파일은 다른 SH를 호출하지 않습니다. 07은 명시 구성원이 본인 하나인지 확인하는 예제 조건입니다.

03 / RUN ON CENTOS
CentOS에서 실행하고 TXT 가져오기
SH 옮기기 → 문법 확인 → 실행 → TXT 가져오기 순서로 진행합니다. 아래 안내를 따라 본인의 CentOS 실습 VM에서 실행해주세요. 사이트에서 명령을 실행하지는 않습니다.

        
1
새 실습 폴더로 SH 옮기기
공유 폴더나 파일 전송 도구로 저장한 SH를 옮깁니다. 실제 과제 최종본과 분리된 새 폴더에서 진행해주세요. 같은 이름의 결과 TXT는 실행할 때 새로 기록됩니다.
mkdir -p ~/account-learning
cd ~/account-learning
이 폴더 안에 다운로드한 SH를 넣은 뒤 다음 순서로 진행합니다.
2
Bash 문법 확인
bash -n은 실행하지 않고 문법을 확인합니다. 아무 출력이 없고 종료 상태가 0인지 확인하세요. 오류가 나오면 코드와 표시된 줄을 먼저 다시 봅니다.
3
실행하고 결과 확인
bash 파일명으로 읽어 실행하므로 실행 권한을 777로 줄 필요가 없습니다. 예제는 계정 정보를 조회하고 현재 폴더에 TXT를 만듭니다.
4
TXT를 이 컴퓨터로 가져오기
생성된 를 Windows로 옮깁니다. UTF-8 TXT를 선택하고 01~08 주 결과·근거·상세 상태·SUMMARY·[END]를 확인하세요.
TXT 결과 리뷰로 →

        
실행이 막혔을 때
Linux 폴더와 파일 이름이 맞는지 확인하고, SH가 UTF-8·LF인지 봅니다. 기본 다운로드는 이 형식을 사용합니다. 조회 실패는 CHECK로 기록할 수 있으므로 원문 오류를 함께 읽습니다. BAD만으로 문법 오류나 불필요한 계정이라고 판단하지 않습니다.

04 / REVIEW
결과를, 근거와 함께
통합 TXT 한 파일을 선택하면 01~08 전체 리뷰를 한 화면에서 읽을 수 있습니다. 전체 보기와 항목별 보기를 전환하며 근거와 재확인 방법을 확인하세요. TXT에 기록된 상태를 보존하고 해설을 더합니다. SH 입력과 학생 코드 전체 자동 판정은 지원하지 않습니다.

        
TXT
UTF-8 · .txt · 최대 1 MB · LF/CRLF
선택한 파일은 이 브라우저에서만 읽습니다.
서버 저장·전송·외부 AI 호출은 없습니다.

        
01~08 통합 TXT 또는 한 항목으로 나눈 TXT를 선택해주세요. 통합 파일은 전체 리뷰, 분리 파일은 해당 항목이 자동으로 열립니다.

        
선택 항목의 가상 예시

같은 TXT로 전체·항목별 보기를 전환할 수 있습니다. 리뷰할 항목에서 ‘전체 리뷰’를 선택하면 파일의 검토 범위 전체를, 01~08을 선택하면 해당 항목의 상세 보기를 읽습니다.

TXT에서 확인한 근거
GOOD는 시스템 전체의 안전을 뜻하지 않고, BAD는 학생 코드의 오류를 뜻하지 않습니다. 실행 진위·대상 호스트·실행 코드 일치는 TXT만으로 확인하지 못합니다.
다음 학습과 재확인

사용 여부를 확인합니다
계정의 사용 목적을 검토하고, 미사용이 확실한 계정 정리와 로그인 불필요 계정의 Shell 제한을 학습합니다.
  1. 계정 행과 검색 행 수, 기록된 오류를 확인합니다.
  2. 관리 목적과 실제 사용 중인 서비스, 계정이 필요한 이유를 실습 환경에서 확인합니다.
  3. 미사용이 확실한 경우에만 관리자 검토 아래 필요한 보완을 학습합니다.
  4. 필요한 보완 뒤 같은 스크립트를 다시 실행하고 새 TXT의 근거와 결과를 비교합니다.
cat /etc/passwd |
  grep -E "lp:|uucp:|nuucp:"
echo $?
마지막 숫자는 직전 검색의 종료 상태입니다. 0은 일치 행 있음, 1은 일치 행 없음이며 행 수와 다른 값입니다. 오류는 출력 원문도 함께 확인합니다.

지원 TXT 양식과 인식 실패 안내
현재 기본형 01~08 통합 보고서와 Scope: 01-only부터 Scope: 08-only까지의 단일 항목 보고서를 읽습니다. 분리 파일의 Scope는 검토 범위를 뜻하며 실행 진위를 증명하지 않습니다. 번호 구간과 주 RESULT가 필요합니다. 누락·중복·SUMMARY 차이·[END] 부재는 확인 필요로 알리며 새 판정으로 바꾸지 않습니다.
[Report 1] ...
Scope: 01-only
========== [01] Default account check ==========
근거 원문
RESULT: BAD -- 설명
========== SUMMARY ==========
GOOD=0 BAD=1 CHECK=0 SKIP=0 TOTAL=1
[END]
다른 양식은 원문을 보존하고 지원 형식 확인을 안내합니다. 읽을 수 없는 인코딩은 원본을 남긴 채 UTF-8 사본으로 저장해주세요.
